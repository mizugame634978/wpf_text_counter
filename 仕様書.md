# 仕様書: 文字カウンター

## 目的
`INotifyPropertyChanged` と双方向バインディングを理解する。

## 学習ポイント
- `{Binding}` の基本的な書き方
- `INotifyPropertyChanged` の実装方法
- `Mode=TwoWay` と `Mode=OneWay` の違い
- ViewModelのプロパティがUIを更新する仕組み

---

## 画面仕様

```
┌────────────────────────────┐
│  文字カウンター            │
│                            │
│  ┌──────────────────────┐  │
│  │ (入力エリア)          │  │
│  │                      │  │
│  └──────────────────────┘  │
│                            │
│  文字数: 0                 │
│  単語数: 0                 │
│  行数:   1                 │
└────────────────────────────┘
```

## 機能要件
1. 複数行テキストボックス（TextBox）に文字を入力できる
2. 文字を入力するたびに、以下がリアルタイムで更新される
   - 文字数（スペース含む）
   - 単語数（スペース区切り）
   - 行数

## 実装要件

### ViewModel
- クラス名: `MainViewModel`
- `INotifyPropertyChanged` を実装する
- 以下のプロパティを持つ
  - `InputText` (string) — TextBoxと双方向バインド
  - `CharCount` (int) — 文字数
  - `WordCount` (int) — 単語数
  - `LineCount` (int) — 行数
- `InputText` のセッターで、各カウントを自動計算して更新する

### View
- `DataContext` に `MainViewModel` をセットする
- TextBox の `Text` を `InputText` に `TwoWay` でバインドする
- `UpdateSourceTrigger=PropertyChanged` を使い、入力のたびに即時反映させる
- 各カウントは `TextBlock` で表示する

## ヒント
```csharp
// INotifyPropertyChanged の基本実装
public class MainViewModel : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler? PropertyChanged;

    protected void OnPropertyChanged(string propertyName)
        => PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
}
```

```xml
<!-- UpdateSourceTrigger の使い方 -->
<TextBox Text="{Binding InputText, Mode=TwoWay, UpdateSourceTrigger=PropertyChanged}" />
```
